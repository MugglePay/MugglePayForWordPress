MugglePay — это платежный шлюз для WooCommerce, позволяющий принимать криптовалютные платежи (USDC, USDT, Ethereum, Solana) с мгновенными расчетами.

== Описание ==

Как настроить MugglePay в WooCommerce:

* [Зарегистрируйтесь на платформе MugglePay👑 и получите API-ключ](https://merchants.mugglepay.com/user/register?ref=MP915E5AD67F03)
* Загрузите и активируйте MugglePay для WooCommerce.
* Включите MugglePay в WooCommerce > Настройки > Платежи > MugglePay.
* Введите API-ключ из MugglePay.
* MugglePay автоматически появится в способах оплаты при оформлении заказа.

= Поддерживаемые валюты = 
* USDT (Tether USD) в сетях Arbitrum, Ethereum, Celo, Ton, Tron
* USDC (Circle USD) в сетях Base, Solana, Ethereum

== Внешние сервисы ==

Все платежи и возвраты обрабатываются через API MugglePay. Адрес API: https://api.mugglepay.com/v1. Подробности можно найти на GitHub: https://github.com/MugglePay/MugglePay.

== Установка ==

1. Откройте панель управления WordPress.
2. Перейдите в ‘Плагины > Добавить новый’ и найдите ‘MugglePay’.
3. Активируйте MugglePay на странице управления плагинами.

Если хотите установить вручную, скачайте плагин здесь: https://wordpress.org/plugins/mugglepay.

== Часто задаваемые вопросы ==

Вам необходимо создать учетную запись в системе MugglePay <https://merchants.mugglepay.com/user/register>.
