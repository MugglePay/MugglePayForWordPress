MugglePay is a WooCommerce payment gateway for accepting cryptocurrency payments (e.g. USDC, USDT, Ethereum, Solana) with real-time settlement.

== Description ==


How to setup MugglePay on WooCommerce webstore:

* [Register at MugglePay Merchant Portal👑 and get the API Key](https://merchants.mugglepay.com/user/register?ref=MP915E5AD67F03)
* Download and Activate MugglePay For WooCommerce.
* Enable from WooCommerce > Settings > Payments > MugglePay
* Enter API Key from MugglePay Merchant Portal👑
* MugglePay will automatically appear to customer on checkout.


= Currencies Support = 
* USDT (USD Tether) on Arbitrum, Ethereum, Celo, Ton, Tron
* USDC (USD Circle) on Base, Solana, Ethereum


== External Services ==

Any of your order payments and refund processes will be serviced through the MugglePay API, with the interface address at https://api.mugglepay.com/v1. You can visit https://github.com/MugglePay/MugglePay for more related content."


== Installation ==

1. Open your your WordPress dashboard
2. Visit ‘Plugins > Add New’, and Search for ‘MugglePay’
3. Activate MugglePay from your Plugins page.

If you want to add it manually, you can download the plugin here: https://wordpress.org/plugins/mugglepay


== Frequently Asked Questions ==

You will need to set up an account on MugglePay Merchant Portal <https://merchants.mugglepay.com/user/register>.
