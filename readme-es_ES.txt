MugglePay es una pasarela de pago de WooCommerce para aceptar criptomonedas (USDC, USDT, Ethereum, Solana) con liquidación en tiempo real.

== Descripción ==

Cómo configurar MugglePay en WooCommerce:

* [Regístrate en el Portal de Comerciantes de MugglePay👑 y obtén tu API Key](https://merchants.mugglepay.com/user/register?ref=MP915E5AD67F03)
* Descarga y activa MugglePay para WooCommerce.
* Habilítalo desde WooCommerce > Configuración > Pagos > MugglePay.
* Introduce la API Key desde el Portal de Comerciantes de MugglePay👑.
* MugglePay aparecerá automáticamente en el pago para los clientes.

= Monedas compatibles = 
* USDT (Tether USD) en Arbitrum, Ethereum, Celo, Ton, Tron
* USDC (Circle USD) en Base, Solana, Ethereum

== Servicios externos ==

Todos los pagos y reembolsos de pedidos se procesarán a través de la API de MugglePay, en la dirección https://api.mugglepay.com/v1. Puedes visitar nuestro GitHub para más información: https://github.com/MugglePay/MugglePay.

== Instalación ==

1. Abre tu panel de administración de WordPress.
2. Ve a ‘Plugins > Añadir nuevo’ y busca ‘MugglePay’.
3. Activa MugglePay desde la página de plugins.

Si deseas instalarlo manualmente, puedes descargarlo aquí: https://wordpress.org/plugins/mugglepay

== Preguntas frecuentes ==

Debes registrarte en el Portal de Comerciantes de MugglePay <https://merchants.mugglepay.com/user/register>.
