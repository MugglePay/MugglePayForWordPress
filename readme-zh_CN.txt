MugglePay 是 WooCommerce 的加密货币支付网关，支持 USDC、USDT、Ethereum、Solana 等，提供实时结算。

== 描述 ==

如何在 WooCommerce 商店上设置 MugglePay：

* [注册 MugglePay 商户门户👑 并获取 API 密钥](https://merchants.mugglepay.com/user/register?ref=MP915E5AD67F03)
* 下载并激活 MugglePay For WooCommerce 插件。
* 在 WooCommerce > 设置 > 支付 > MugglePay 启用。
* 输入从 MugglePay 商户门户获取的 API Key👑。
* 结账时，MugglePay 将自动出现在客户支付选项中。

= 支持的币种 = 
* USDT（Tether 美元）支持 Arbitrum、Ethereum、Celo、Ton、Tron
* USDC（Circle 美元）支持 Base、Solana、Ethereum

== 外部服务 ==

您的订单支付和退款流程将通过 MugglePay API 处理，接口地址为 https://api.mugglepay.com/v1。您可以访问 GitHub 了解更多信息: https://github.com/MugglePay/MugglePay。

== 安装 ==

1. 登录 WordPress 仪表盘
2. 访问‘插件 > 添加新’，搜索‘MugglePay’
3. 在插件页面激活 MugglePay

如果您想手动安装，可以在这里下载插件: https://wordpress.org/plugins/mugglepay

== 常见问题 ==

您需要在 MugglePay 商户门户注册账号 <https://merchants.mugglepay.com/user/register>。
